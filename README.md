I build forecasting and optimization models and keep them running in production: monthly forecasting pipelines with validation and realized-accuracy tracking, mixed-integer programming for production scheduling, and the data ingestion and orchestration underneath them.

Most of my work lives in private client repositories, so this profile shows open-source contributions and side projects.
