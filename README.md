# Pedro Borges
**Data Scientist | Economist**

I'm a Data Scientist with a background in Economics (B.A., University of São Paulo), specializing in mathematical optimization, causal inference, and end-to-end machine learning. 

My work bridges the gap between statistical rigor and software engineering. I focus on translating complex business constraints into mathematical models and building the infrastructure required to serve them in production.

### Current Focus
- Designing LLM-based agentic workflows for automated time-series forecasting.
- Scaling industrial optimization SaaS products using Mixed-Integer Linear Programming.
- Building backend architectures and RESTful APIs to serve ML models to end-users.
